# 🧩 Programming Patterns  

Репозиторий с заданиями по дисциплине **«Шаблоны программирования»**.  

---

## 📂 Содержание  
В проекте реализованы программы, демонстрирующие применение классических **паттернов проектирования**:  

### 🔹 LinesAndCurves  
- **Мост** (*Bridge*)
- **Декоратор** (*Decorator*)

### 🔹 ObserverEsp32  
- **Наблюдатель** (*Observer*)  
  - 💻 [Демонстрация на Wokwi](https://wokwi.com/projects/393183596789392385)  

### 🔹 CMTest  
- **Команда** (*Command*)  
- **Синглтон** (*Singleton*)  

---

## 🛠 Используемые технологии  
- C# 
- C++/ESP32 (для демонстрации Observer)
